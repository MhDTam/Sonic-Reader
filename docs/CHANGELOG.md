# Release notes / ⁧سجل التغييرات⁩

## 1.0.0 · build 16131

- First curated public-distribution package for GitHub.
- Arabic and English documentation and demonstration screenshots.
- Both reader toolbars now hide and reappear together with a smooth transition.
- Toolbar visibility preserves the document viewport, scroll position and zoom.
- Improved Arabic/English mixed-script selection and number ordering.
- Reused text-selection indexes and reduced repeated work during drag selection.
- Consistent Arabic fonts in notes and settings rows.
- No private conversion endpoint or account credentials in the public APK.
- Optional cloud conversion starts disabled; local reading is ready to use.
- Product-only public signing certificate, without personal contact/location data.
